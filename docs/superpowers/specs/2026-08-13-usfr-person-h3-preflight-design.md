# USFR 人物资产与 H3 后台合规门禁设计

## 目标

在不改变用户可见文字脚本格式、不改变 Seedance 绑定规则、不解析 UI 操作视频且不新增 QC 的前提下，解决两类付费前问题：人物参考图方向/裁切异常，以及 H3 请求绕过官方文档规则和标准合同。

## 已批准边界

1. 所有人物输入在任何付费调用前完成 EXIF 方向修正、显式裁切、1024×1024 PNG 规范化并形成可审计清单。预处理不推断人物身份，不修改绑定数量、顺序或服装策略。
2. 所有 H3 任务必须由后台编译器生成 Prompt。编译依据固定为 MiniMax H3 使用手册与视频扩写 Prompt 全能指南的本地版本化规则快照；请求审计必须拒绝手写 Prompt、缺少文档凭证或绕过编译器的 Payload。
3. H3 全能参考 Prompt 在后台采用六段结构：`subject_definitions`、`summary`、`retention_analysis`、`detailed_description`、`overall_soundscape`、`non_diegetic_music`。正文使用英文；台词和歌词放入 `<d>[Language] ...</d>`；发声人物使用稳定 `(S1)..(Sn)`；批准对白结束后明确静音边界。视频编辑只表达批准变更与保留关系，不重新创作无关剧情。
4. 用户公开文字脚本格式维持现状。公开内容禁止出现模型名、Provider、引用标签、绑定规则、内部阶段、六段 Prompt 或审计信息。
5. 商品/App/服装等核心 offer 的技术、内容与商业成立性在公开文字脚本生成前完成。结果只塑造现有脚本的画面动作、口播、字幕和品牌信息，不添加公开章节或内部字段。
6. 用户 UI 操作视频视为已由用户确认的不可解释确定性媒体块。系统仅依据批准时间窗/位置执行插入、替换或剪辑；禁止 OCR、语义分析、品牌核验和 Prompt 引用。
7. 禁止新增任何 QC 阶段、QC 指标、QC 重试、人工门禁或用户确认环节。现有 QC 保持原样。

## 数据流

```text
输入绑定
→ 人物资产付费前规范化
→ 目标商品/内容/商业成立性分析
→ 现有格式文字脚本
→ 用户确认
→ 路由选择
→ H3 文档规则后台编译（仅 H3）
→ H3 文档凭证与 Payload 审计
→ 单次 Provider 提交
→ 现有装配；UI 媒体按批准位置确定性插入
→ 现有 QC（无新增）
```

## 错误处理

- 人物资产无法满足格式：`PERSON_ASSET_FORMAT_REQUIRED`，付费前停止。
- H3 Prompt 非后台编译产物：`H3_DOCUMENT_PROMPT_REQUIRED`，付费前停止。
- 文档规则版本或 SHA 缺失/过期：`H3_DOCUMENT_CONTRACT_STALE`，付费前停止。
- 六段结构、引用、说话人或 `<d>` 台词不合规：对应 H3 合同错误，付费前停止。
- UI 没有批准位置：使用既有时间线合同阻塞；不得分析 UI 内容来猜位置。

## 非目标

- 不重跑测试 06。
- 不声称 H3 的身份一致性已经稳定。
- 不修改 Seedance Prompt 或人物绑定语法。
- 不增加 QC。
- 不改变用户文字脚本结构。
