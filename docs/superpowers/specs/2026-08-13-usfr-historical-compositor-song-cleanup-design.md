# USFR Historical Compositor and Song Route Cleanup Design

Date: 2026-08-13

## Goal

Remove historical Remotion/UI-sidecar, multi-backend hybrid-compositor, and post-generation song-segment manifest routes from the local `universal-source-fidelity-replication` Skill while preserving every current `video-edit-v2` capability.

## Protected current behavior

The cleanup must not change person or multi-object binding, person asset formatting, product/App action adaptation, source and target marketing analysis, pain-point and selling-point interpretation, Replication Matcher, reverse-script behavior, Seedance/H3 exclusive routing, H3 language and MV editing, 24 fps segmentation, deterministic UI-operation video splice, App asset-board editing, overlays, subtitles, tails, audio-window analysis, UI-monologue protection, voiceover fallback, reconciliation, or final QC.

## Removal boundary

Remove Remotion conditional rendering, local UI Sidecar lifecycle/retention, activation benchmark policy, generated-UI historical backend selection, and their dedicated tests and bundle declarations. Retain current deterministic FFmpeg assembly and current App/UI routes.

Remove the legacy `song-lip-sync-segment-manifest/v1` loader, lineage validator, segment-media renderer, and timeline receipt fields. Current target-song MV remains one H3 edit whose returned `provider_video` enters ordinary deterministic segment assembly. Retain source music/speech/UI-protection window analysis and H3 prompt evidence.

The old `song_lipsync` intake spelling may remain temporarily as an admission alias only. It must not declare or require a legacy assembly manifest and must never select a post-generation provider or local song-segment renderer.

## Verification

Add a structural regression test proving removed modules and route contracts are absent while protected current modules and documented V2 routes remain. Run targeted orchestration, H3, UI-operation, marketing, binding, bundle, and full Skill regression tests. Preserve the protected `source_ui_pixels.py` hash.
