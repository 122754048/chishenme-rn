# 帧锁定人物替换工作流

适用条件：用户只要求把源视频中的人物换为参考人物，并要求镜头、场景、道具、文字、动作、音频和节奏不变。

## 根本原则

生成模型只负责身份区域；所有需要逐字准确或构图准确的内容都是源像素层。特别是手写卡片、字幕、UI、Logo、背景、手和纸张撕裂状态，均不得交给模型重绘。

## 固定流水线

`源视频逐帧解码 → 锚点/遮挡分析 → 人物蒙版局部替换 → 源像素层复合 → 帧级 QC → 已替换帧排版导演板 → 审核 → 视频生成或帧间插值 → 成片 QC`

## 不可绕过的门禁

1. 为每个镜头锚点保存源帧、身份蒙版、替换帧及 QC 收据。
2. 保护层（文字、道具、背景、手）必须从源帧复合，不能由 OCR 转写或提示词复刻。
3. 帧级像素比对必须证明：蒙版外没有非授权改动；文字/字幕可见且完整。
4. 故事板的场景卡只能来自通过 QC 的替换帧。导演板是排版，不是重新绘制。
5. 未有通过的替换帧清单时，禁止调用视频模型或提交已有旧故事板。

## 常见失败与对应规则

| 症状 | 根因 | 规则 |
| --- | --- | --- |
| 场景、动作与原片不一致 | 以文字脚本驱动整帧重绘 | 源帧作为底板，限制生成区域至身份蒙版 |
| 卡片或字幕消失 | 为避免乱码而留白/重绘文字 | 文本从源帧像素层保留，不让模型生成 |
| 手压住卡片关系错误 | 未建立层级与遮挡关系 | 固定“背景→身份→手→卡片→屏幕字幕”层序，并在每帧 QC |
| 故事板看似漂亮但不能指导复刻 | 故事板先生成、替换帧后补 | 必须先产出通过 QC 的替换帧，再作确定性导演排版 |

## 适合的工具分工

- 人物替换：人脸识别/InstantID、ReActor 或带蒙版的局部重绘；不允许全图重绘。
- 文字和叠层：源像素直接复合，或在确实需要改文案时用确定性字体渲染并做 OCR 校验。
- 故事板：图像排版工具，只放已验收的替换帧和边栏时间码。
- 视频：若要求严格源动作，优先逐帧替换/跟踪后合成；生成视频只作为身份区或无法修复动作的受控补充。
