# USFR 服务端部署操作手册

本压缩包是可独立部署的 Python 全量视频服务，不读取本机 `.codex`、本地 Skill 目录或用户运行记录。完整配置解释见 `deployment/中文部署配置手册.md`。

## 1. 准备

服务器需安装 Docker Desktop 或 Docker Engine，并能执行 Docker Compose。将 `.env.example` 复制为 `.env`，只在 `.env` 中填写密钥，不要修改代码文件。

必须填写的核心配置包括：

- `USFR_CAPABILITY_SECRET`：至少 32 字节随机字符串；
- `USFR_ALLOWED_OSS_HOSTS`：允许导入的阿里云 OSS 域名；
- `USFR_OSS_ENDPOINT`、`USFR_OSS_BUCKET`、`USFR_OSS_ACCESS_KEY_ID`、`USFR_OSS_ACCESS_KEY_SECRET`、`USFR_OSS_PUBLIC_BASE_URL`；
- `OPENAI_API_KEY`、`OPENAI_MODEL` 及模型配置摘要；
- RunningHub、Seedance、Whisper、TTS/对口型等实际使用能力对应的配置。

默认 `USFR_TEMPORARY_RETENTION_SECONDS=0`。任务最终成功或不可恢复失败后，MinIO 中的工作文件进入立即清理队列；Redis 任务状态和任务 Token 默认保留 7 天；原始 OSS 素材和最终 OSS MP4 永久保留。

## 2. 启动

在解压目录执行：

```powershell
docker compose -f deployment/docker-compose.yml config
docker compose -f deployment/docker-compose.yml up -d --build
docker compose -f deployment/docker-compose.yml ps
docker compose -f deployment/docker-compose.yml logs --tail=200 api worker sweeper
```

默认公共 API 地址为 `http://服务器地址:8080`。Redis 与 MinIO 不应开放到公网。

## 3. 公共 HTTP 接口

公共 OpenAPI 只允许三个业务接口：

- `POST /api/v1/jobs`：提交永久 OSS URL，自动导入并启动；
- `GET /api/v1/jobs/{job_id}`：查询状态、取得脚本/故事板审核内容或最终 URL；
- `POST /api/v1/jobs/{job_id}/review`：确认或修改当前脚本/故事板。

创建任务时 Web 生成 `Idempotency-Key`。创建响应返回 `job_id` 与 `access_token`；后续请求只在 `Authorization: Bearer <access_token>` 中携带 Token。

每条路线都固定经过两次用户审核：先文字脚本，后故事板。用户确认故事板后，服务自动生成、拼接、QC、上传最终 MP4，不需要调用方提交 SHA、MIME、大小、时长、revision、Provider 参数或 Seedance Prompt。

## 4. UI 与音频

- UI 截图：只在源视频 UI 区间做受限确定性重建；
- UI 操作视频：剪掉旧 UI 区间，将新操作视频按原时间轴静音替换；
- `USFR_UI_REBUILD_ENABLED=false`：没有 UI 截图或官方商店链接时，原视频 UI 保持不变；提交截图或商店链接时目标 UI 链路始终开启；
- 两者同时上传：操作视频负责动作，截图负责样式、文字和关键状态校准；
- 上传歌曲且源视频是演唱 MV：执行歌词、人物演唱脚本、Seedance 音频编译和必要对口型；
- 源视频不是演唱 MV：上传音频只作为背景音乐替换。

## 5. 验证

没有 Docker 时可先验证真实 TCP 公共接口：

```powershell
python -B validation/e2e/local_public_http_smoke.py
```

部署后检查：

```text
GET /healthz
GET /readyz
```

若 `/readyz` 返回 503，先检查 `.env` 中 OSS、OpenAI、RunningHub、Seedance 和各实际启用工作流配置，不要通过关闭质量门槛绕过 readiness。
