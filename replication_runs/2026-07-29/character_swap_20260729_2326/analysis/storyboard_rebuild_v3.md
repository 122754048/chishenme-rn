# V3：帧锁定人物替换故事板

旧 `segment_01_v1.png` 与 `segment_01_v2.png` 已撤销，不能用于审核、上传或 Seedance。

执行顺序固定为：

1. 从源视频解码锚点帧（不可由接触表替代）。
2. 对每帧只在“脸部/必要发际线”蒙版内替换为参考人物身份。
3. 以源帧像素恢复背景、衣服、手、白色卡片、手写文字、撕裂纸片和黄色“अनइंस्टॉल!”字幕；按原遮挡关系合成。
4. 对替换帧做身份、遮挡、文字、字幕、背景四项 QC；任何一项失败则该帧返工。
5. 仅用 QC 通过的替换帧，确定性排版成导演故事板；场景卡不再通过 Image2 重绘。
6. 用户确认 V3 故事板后，才允许进入后续视频阶段。

## V3 验收

- 每张出现卡片的画面，卡片与原视频同一帧文字、位置、撕裂状态一致。
- 三处黄色字幕均存在、位置一致、字形不乱码。
- 房间、镜头构图、手部与衣服保持源片像素；唯一可见变化是人物身份。
- 导演故事板标注全局时间码，但标注位于版式边栏，不能覆盖或替代场景内原文。
