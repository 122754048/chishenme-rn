失败处理

输入或意图不明确

停在预检；不创建正式任务、不产生费用。

分析/故事板失败

保留已有检查点；重试当前阶段，不重复分析有效缓存。

Provider 明确失败

标记失败；允许安全重试，成功行不受影响。

Provider 状态不明

进入待对账；找到 Task ID 后恢复，绝不盲目重提。

QC 失败

阻止交付；保存诊断信息，按允许的恢复策略重跑。

服务器重启

Redis 检查点和对象存储恢复任务；已提交 Provider 任务不重复。

MVP 验收测试

单条路线

八槽位、语言、脚本/故事板审批、最终 MP4。

批量路线

换人、换歌、换语言、明确一一对应，且绝不排列组合。

样片授权

样片未确认时后续 Provider 调用必须为 0。

并发与恢复

默认并发 5、部分成功、只重试失败行、重启恢复。

缓存与权限

同员工命中；跨员工隔离；管理员转移后权限切换。

费用与安全

50 条、¥10,000 熔断、Key 不出服务端、日志无秘密。
