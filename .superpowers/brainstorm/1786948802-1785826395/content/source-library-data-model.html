隔离与转移规则

员工 B 上传相同原片

不能命中员工 A 的缓存；不会泄露该原片是否已存在。

管理员转移所有权

Source、分析、脚本、故事板、成片和任务整体转移，不复制。

删除原片

停止后续免上传复刻；默认保留分析、脚本、故事板和最终成片。

分析版本升级

旧缓存不覆盖；按新版本生成另一份缓存，可由任务选择复用或重析。

缓存命中条件： owner_user_id + source_sha256 + analysis_profile + analyzer_model_sha256 + contract_version 完全一致。
